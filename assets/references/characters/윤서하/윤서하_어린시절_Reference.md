# 윤서하(어린 시절) 시각 레퍼런스

- 용도: AI 이미지·영상 생성 시 유지할 승인된 윤서하 어린 시절 외형 기준
- 상태: `accepted` ([[project/decisions/DEC-009-윤서하-어린시절-외형-확정]])
- Primary reference: [[assets/references/characters/윤서하/윤서하_어린시절_레퍼런스.png]] (정면/후면/클로즈업 다각도 구성)
- 용도 메모: 프롤로그 첫 장면(장례식장)에서 사용 예정이라는 인간 지시가 있었음. 정확한 씬 배치·타임코드는 아직 Shot 문서에 반영되지 않음

> 아래 서술은 DEC-009로 승인된 고정(locked) 사실이다. 성인 시점 [[assets/references/characters/윤서하/Seoha_Visual_Reference]](DEC-005 확정)와는 별개의 연령대 레퍼런스이며, 두 문서를 동일 인물의 동일 시점 기준으로 혼용하지 않는다 — 동일 인물 연속성 규칙은 DEC-009에서 다루지 않은 별도 미결 사항이다.

## 1. 전체 인상

- 미취학~저학년 아동 정도의 연령 인상 (정확한 나이는 미정)
- 평균 체형의 아동 체구
- 표정은 무표정에 가깝고 다소 진지하거나 관찰하는 듯한 인상

## 2. 얼굴 특징 (관찰)

- **얼굴형:** 둥근 계란형
- **눈:** 짙은 갈색, 또렷한 눈매
- **눈썹:** 옅고 자연스러움
- **코:** 작고 낮음 (아동 특유의 비율)
- **입술:** 작고 옅은 핑크빛
- **피부:** 밝고 매끄러운 톤
- **기본 표정:** 무표정, 정면을 응시하는 다소 경계하는 인상

## 3. 헤어스타일 (관찰)

- **색상:** 짙은 검정~짙은 갈색
- **스타일:** 단발 보브, 턱선 근처에서 끝나는 길이
- **앞머리:** 눈썹 근처까지 내려오는 일자 뱅
- **디테일:** 클로즈업 이미지 기준 본인 왼쪽 측면(화면상 오른쪽)에 작은 헤어핀 확인됨 — 정확한 형태·개수는 추가 확인 필요
- **참고:** 성인판 [[assets/references/characters/윤서하/Seoha_Visual_Reference]]와 마찬가지로 보브+뱅+헤어핀 조합이 관찰되나, 동일 인물의 시각적 연속성을 의도한 것인지는 인간 확인 전까지 `정보 없음`

## 4. 체형과 자세 (관찰)

- 아동 평균 체형, 팔다리가 짧고 통통한 비율
- 정면 기준 차렷 자세, 팔은 몸 옆에 자연스럽게 내려짐

## 5. 의상 (관찰)

- **아우터:** 짙은 남색/검정 가디건, 흰색 피터팬 카라(둥근 옷깃)가 셔츠 위로 드러남
- **이너:** 흰색 셔츠
- **하의:** 짙은 남색/검정 주름치마
- **양말:** 흰색 크루삭스
- **신발:** 검정 메리제인 구두

## 6. 카메라·조명 레퍼런스

- 중립 회색 스튜디오 배경
- 균일한 소프트 조명
- 눈높이 카메라, 정면/후면/클로즈업 3분할 구성

## 인간 승인

- 승인자: 사용자
