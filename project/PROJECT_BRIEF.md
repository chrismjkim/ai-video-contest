# 프로젝트 브리프

## 확정된 프로젝트 사실

- 두 명의 친구가 팀으로 AI 숏드라마 공모전에 참가한다.
- 목표 공모전은 [2026 OYE AI 숏드라마 챌린지: EP.01](https://oyecontent.wixstudio.com/oyeshortdrama)이다.
- Obsidian을 사람과 LLM이 함께 쓰는 장기 기억 Wiki로 사용한다.
- Codex Orchestrator가 필요한 검토를 서브에이전트에게 위임하고 결과를 종합한다.
- Higgsfield를 포함한 AI 영상 생성 결과, 실패 원인 가설, 개선 실험을 Run 단위로 축적한다.
- Wiki는 일반 영화학 백과사전보다 프로젝트 고유의 인간 결정과 근거 보존을 우선한다.

## 현재 단계

워크스페이스 초기화 단계다. 창작 기획과 제작 일정은 아직 확정하지 않았다.

## 범위 밖

- 일반적인 영화 이론을 포괄적으로 정리하는 일
- 확인되지 않은 공모전·플랫폼 정보를 사실처럼 저장하는 일
- 인간이 승인하지 않은 에이전트 제안을 Canon으로 확정하는 일

## 아직 기록되지 않은 운영 정보

- 팀원 이름과 역할 분담
- 예산 및 유료 생성 한도
- 회의 주기와 승인 방식
- 대용량 미디어 저장·백업·버전 정책
- 세부 제작 일정

관련 미결 항목은 [[project/OPEN_QUESTIONS]]에서 관리한다. 공모전 제약은 [[knowledge/CONTEST_RULES]]를 단일 원본으로 사용한다.

## 변경 규칙

이 문서의 확정 사실을 바꿀 때는 인간이 승인한 `DEC-*` 기록을 연결한다.
