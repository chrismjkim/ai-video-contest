# 아이디어 및 폐기안 기록

아이디어를 잊지 않되 현재 Canon과 섞지 않는 곳이다. 짧은 아이디어는 아래 표에, 근거와 논의가 긴 아이디어는 `templates/IDEA.md`로 개별 기록한다.

상태는 `proposed`, `rejected`, `promoted`, `superseded` 중 하나를 사용한다. `promoted`는 연결된 `accepted` Decision과 Canon 반영이 모두 끝난 경우만 사용한다.

현재 등록된 아이디어는 없다.

|---|---|---|---|---|
