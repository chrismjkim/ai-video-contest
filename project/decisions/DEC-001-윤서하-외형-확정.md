# 윤서하 외형 확정

## 결정할 질문

윤서하의 외형, 기본 교복, 고정 액세서리를 현재 시각 레퍼런스 가이드의 내용으로 확정할 것인가?

## 결론

[[assets/references/characters/윤서하/Seoha_Visual_Reference]]에 기록된 얼굴, 헤어스타일, 체형, 기본 교복, 신발, 머리핀과 손목 밴드 기준을 윤서하의 확정 외형으로 채택한다.

Primary reference 이미지의 실제 파일 지정은 이번 결정에 포함하지 않는다. 분리 전 생성 입력이 지목한 `Seoha_2.png`가 현재 폴더에 없다. 인간이 `서하_얼굴_정면.png`와 `서하_전신_정면.png`를 가장 가까운 후보로 확인했지만, 최종 primary 1장은 아직 선택하지 않았다.

## 상태

`accepted`

## 맥락과 근거

- 윤서하 reference 이미지 생성에 사용한 문서와 PNG 8개가 존재한다.
- 인간이 윤서하의 외형을 확정한다고 명시했다.
- 생성 당시 문서 원문은 [[production/runs/RUN-REF-YUNSEOHA-001]]에 보존한다.
