# 소품 디자인 확정: 영정 사진·조직 외투 생략·살풀이 도구·조직 UI 패드형태

## 결정할 질문

`production/PROP_INDEX.md`의 5개 소품(PROP-001, 002, 003, 004, 005) 시안 중 무엇을 채택하는가?

## 결론

### PROP-001 — 어머니 영정 사진

제안된 설계(초점 흐림으로 얼굴 비식별)를 **그대로 승인**한다.

### PROP-002 — 서하의 조직 외투 → 소품 자체를 두지 않음

**조직 외투를 만들지 않는다.** 서하는 이미 승인된 [[assets/references/characters/윤서하/Seoha_Visual_Reference]](DEC-005) 교복 차림만으로 등장한다. IDEA-005·SCENARIO_DRAFT.md 본문의 "교복 위에 조직의 외투를 걸친 현재의 서하"라는 서술은 이 결정으로 **대체**된다 — 두 문서에 수정 기록을 남긴다.

### PROP-003 — 살풀이 도구: 흰 수건 + 신칼(초승달형 낫칼)

사용자가 첨부한 두 레퍼런스 이미지를 identity anchor로 확정한다.

- **왼손**: 살풀이춤 스타일의 흰 수건(긴 흰 천), 첫 번째 첨부 이미지 참고
- **오른손**: 초승달 모양의 전통 무속 낫칼(신칼류) 한 자루, 두 번째 첨부 이미지 참고
- **연출 제약**: 칼로 직접 베는 장면은 화면에 나오지 않는다. 살풀이 절정은 **방울 소리와 함께 화면이 검은색으로 전환**되며 다음 장면으로 넘어간다.
- 이는 PROP-003 문서의 "방향 A(무속 의식구)"를 구체화한 것이며, "방향 B(실질적 도구로 베는 장면)"는 채택하지 않는다.

### PROP-004·PROP-005 — 조직 판정/관측 화면: 패드(태블릿) 형태

두 화면 모두 벽면 대시보드가 아니라 **태블릿(패드) 디바이스 화면**으로 통일한다. 세 번째 첨부 이미지(어두운 베젤의 태블릿, 키보드 케이스 거치대 형태)를 물리적 디바이스 형태의 레퍼런스로 삼는다. 화면 내부 UI 내용(필드·색상 구분)은 기존 PROP-004/005 시안 방향을 유지하되, 디바이스는 패드로 변경한다.

## 상태
