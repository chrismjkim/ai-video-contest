# 조직 판정·관측 화면 디바이스를 데스크 모니터로 변경

## 결정할 질문

[[project/decisions/DEC-011-소품디자인-확정]]에서 PROP-004·PROP-005(조직 판정/관측 화면)를 패드(태블릿) 디바이스로 확정했다. 그러나 `LOC-006-조직-사무실` 장소 레퍼런스에 이미 데스크 대형 모니터에 표시된 판정 화면 스타일의 생성 이미지([[assets/references/environments/LOC-006-조직-사무실/조직_사무실_Reference]] 폴더의 생성본)가 존재한다. 이 기존 이미지를 레퍼런스로 쓰도록 디바이스 형태를 변경하는가?

## 결론

**PROP-004·PROP-005의 디바이스를 패드에서 데스크 대형 모니터(듀얼 모니터)로 변경한다.** [[project/decisions/DEC-011-소품디자인-확정]] 중 "패드 형태" 부분만 이 결정으로 **supersede**하며, DEC-011의 나머지 항목(PROP-001, PROP-002 생략, PROP-003)은 그대로 유효하다.

`LOC-006-조직-사무실` 폴더의 기존 생성 이미지(46acc28d-eb48-4f40-b7aa-cfebf39653c0.png)를 두 화면의 **비주얼·UI 스타일 레퍼런스**로 채택한다: 어두운 다크 테마 대시보드, 좌측 "대상 분석"류 패널(원형 게이지, 인물 이미지, 텍스트 필드), 우측 "대조 검색"류 패널(인물 썸네일·파형), 듀얼 모니터 구성.

## 이 결정이 다루지 않는 것 — 인간 확인 필요

기존 생성 이미지를 검토하는 과정에서 두 가지 불일치를 발견했다. 이 결정에서는 채택하지 않으며, 별도 확인이 필요하다.

1. **용어 불일치**: 기존 이미지 화면에는 "오염도"라는 용어와 78% 수치가 쓰여 있다. 그러나 `project/SCENARIO_DRAFT.md`·`CANON.md`(DEC-010)에서 확정된 Canon 용어는 **"잠식도"**다. PROP-004/005의 실제 텍스트는 기존 이미지를 그대로 복사하지 않고 **Canon 용어인 "잠식도"를 사용**한다 — 비주얼 스타일만 참고하고 텍스트 내용은 따르지 않는다.
2. **조직명 노출**: 기존 이미지 배경에 "무형관리국"이라는 조직명과 "보이지 않는 것을 기록하다"라는 슬로건이 큼직하게 노출되어 있다. 이 조직명은 `CANON.md`·`SCENARIO_DRAFT.md` 어디에도 확정된 적이 없다. 이 결정은 조직명을 확정하지 않으며, PROP-004/005 클로즈업 인서트(화면 확대 샷)에는 이 배경 텍스트가 프레임에 들어가지 않을 가능성이 높아 당장 충돌하지 않지만, 인간이 조직명을 확정할지 별도로 정해야 한다.

## 2026-09-10 추가 승인 (당일 후속)

§"이 결정이 다루지 않는 것"의 두 항목이 같은 날 해결됐다.

1. **"오염도" vs "잠식도"**: **잠식도**가 맞다. PROP-004/005 화면 텍스트는 잠식도로 확정.
2. **"무형관리국" 조직명**: 채택하지 않는다. 화면 클로즈업 인서트에 조직명을 노출하지 않으며, 조직의 정식 이름은 여전히 미정(Canon 아님)으로 남긴다.
