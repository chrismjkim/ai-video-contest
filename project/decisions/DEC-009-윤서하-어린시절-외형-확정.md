# 윤서하(어린 시절) 외형 확정

## 결정할 질문

프롤로그 첫 장면(장례식장)에 쓸 예정으로 추가된 윤서하 어린 시절 레퍼런스 이미지를 정식 외형으로 확정하는가?

## 결론

윤서하 어린 시절의 외형은 [[assets/references/characters/윤서하/윤서하_어린시절_레퍼런스.png]]로 확정한다.

관찰 기반 외형 서술은 [[assets/references/characters/윤서하/윤서하_어린시절_Reference]]를 그대로 승인한다: 둥근 계란형 얼굴, 짙은 검정~짙은 갈색 단발 보브(눈썹 근처 일자 뱅), 본인 왼쪽 측면의 작은 헤어핀, 아동 평균 체형, 짙은 남색/검정 가디건 + 흰색 피터팬 카라 셔츠 + 짙은 남색/검정 주름치마 + 흰색 크루삭스 + 검정 메리제인 구두.

용도: 프롤로그 첫 장면(장례식장) 회상/플래시백. 정확한 씬 배치·타임코드는 이 Decision에 포함하지 않으며 추후 해당 Shot 문서에서 정한다.

이 Decision은 어린 시절 외형 자체만 확정하며, 성인판 [[assets/references/characters/윤서하/Seoha_Visual_Reference]](DEC-005)와 동일 인물로서의 연속성 디테일(헤어핀 정확한 좌/우, 승계 관계 등)을 새로 규정하지 않는다. 두 시점 모두 보브+뱅+헤어핀 조합이 관찰되나 이는 각 문서의 독립적 관찰 기록이다.

## 상태
