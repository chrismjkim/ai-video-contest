# 형체 피 분장 강화 확정 (DEC-013 대체)

## 결정할 질문

RUN-SH-002-001(Part B) 실제 생성 결과 확인 후, 사용자가 DEC-013의 "작은 핏방울만, 상처·베인 자국 없음" 수준으로는 "악귀"라는 느낌이 부족하다고 판단. 얼굴이 피에 더 흠뻑 젖은 느낌과 상처(베인 자국 등) 표현까지 허용할지 결정.

## 결론

형체의 피 분장을 다음과 같이 강화한다.

- 얼굴 전체에 넓게 번지고 흘러내린 듯한 피 표현 허용(기존 "작은 핏방울 흩뿌림" 수준보다 훨씬 강한 임팩트)
- **베인 자국·상처 표현도 허용** — DEC-013의 "상처·베인 자국 없음" 원칙을 폐기. RUN-SH-002-001 결과물에서 이마에 나타난 베인 자국(scratch)을 오히려 자연스러운 기준으로 인정하고 유지
- 다만 과도한 노출성 신체 훼손(뼈·근육 노출, 절단 등 그로테스크 표현)까지 가는 것은 아님 — 스킬 §20 기준 "함의 중심" 원칙은 유지하되, 허용 강도의 상한선을 상향
- 이준호 형체(SH-002, SH-003)와 서하 형체(SH-008, SH-009) 모두 동일하게 강화된 기준 적용
- 옷은 기존과 동일하게 깨끗한 상태 유지(피는 얼굴에 한정)

## 상태

`accepted`

## 맥락과 근거

- RUN-SH-002-001에서 DEC-013 수준(작은 점 몇 개)으로 생성된 결과물을 사용자가 직접 확인 후, "악귀"라는 정체성이 시각적으로 충분히 전달되지 않는다고 판단
- 인간이 직접 강도 상향과 상처 허용 여부를 명시적으로 결정함(AskUserQuestion 응답: "상처 느낌까지 허용", "이마 베인 자국 유지")

## 정정·추가 기록

- 2026-09-12: 사용자가 "이준호는 원래 이마에 상처가 있다"고 알려줌 — 확인 결과 DEC-006([[project/decisions/DEC-006-이준호-외형-확정]])에 이미 "이마의 붉은 선 형태 흉터"가 이준호의 영구적 외형 특징으로 locked돼 있었음. 즉 RUN-SH-002-001에서 관찰된 이마 자국은 이번에 새로 생긴 상처가 아니라 **기존 흉터가 레퍼런스 이미지에서 정상적으로 재현된 것일 가능성**이 있음. 이 문서의 "이마 베인 자국을 새 상처로 허용"이라는 서술은 부정확할 수 있어 정정: 이준호의 기존 흉터(항상 존재)와 이번 DEC-014로 추가되는 피 얼룩(형체 등장 시에만, 훨씬 넓고 진함)은 서로 다른 요소로 구분해서 프롬프트에 반영함(SH-002 Part B v4 참고). DEC-014의 핵심 결정(피 표현 강도 상향)은 유효, "새 베인 자국 허용" 부분만 이 정정으로 보완
