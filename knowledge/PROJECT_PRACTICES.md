# Higgsfield 및 AI Video 프로젝트 학습

## 저장 범위

여기는 일반 프롬프트 모음이나 영화학 백과사전이 아니다. 이 프로젝트에서 반복적으로 필요한 플랫폼 사실, Run으로 관찰한 현상, 재현된 생성 원칙만 저장한다.

## 증거 상태

| 상태 | 의미 |
|---|---|
| `platform-fact` | 공식 문서나 현재 UI에서 확인했으며 출처·확인일이 있음 |
| `observed` | 연결된 Run 출력에서 직접 관찰함 |
| `working-hypothesis` | 원인 또는 개선안에 대한 아직 검증되지 않은 해석 |
| `accepted-practice` | 반복 Run 또는 고영향 검증을 거쳐 인간이 프로젝트 원칙으로 승인함 |
| `retired` | 후속 증거로 더 이상 사용하지 않음 |

한 번의 성공이나 실패를 일반 규칙으로 승격하지 않는다. 관찰과 원인 가설을 분리하고 관련 Run을 연결한다.

## 공통 실패 분류

Run의 주 실패는 하나를 선택하고 필요하면 보조 분류를 추가한다.

- `narrative`: 컷의 서사 기능 또는 정보 전달 실패
- `adherence`: 프롬프트·제약 미준수
- `identity`: 얼굴·체형·인물 정체성 드리프트
- `wardrobe-prop`: 의상·소품 일관성
- `spatial-action`: 공간·시선·동작 연속성
- `camera`: 프레이밍·렌즈감·카메라 움직임
- `performance-anatomy`: 연기·표정·신체·물리 오류
- `lighting-color`: 조명·색·시간대 불일치
- `temporal-artifact`: 플리커·모핑·시간축 파손
- `technical`: 생성 오류·파일·플랫폼 문제
