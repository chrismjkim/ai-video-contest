## 사용 규칙

1. 각 문서의 `구도 후보`는 아이디어 단계의 계획이며, 새 창작 선택은 `proposed`로 표시한다.
2. 특정 구도를 제작 대상으로 승인하면 `templates/SHOT.md`로 `SH-*` 문서를 만들고, 해당 행의 `향후 Shot`에 링크한다.
3. 인물·외형·형체 수처럼 Canon 또는 accepted Decision에 속하는 사실은 Location 문서에서 새로 정하지 않는다.
4. 장소를 합치거나 분리하는 선택이 서사·연속성에 영향을 주면, 영향을 기록한 뒤 인간 결정을 받는다.
